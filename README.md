# 阿爾比恩量化帝國 - 黑市製造利潤與皇家製造套利系統

本系統專為《阿爾比恩 Online (Albion Online)》皇家大陸黑市交易與六大皇家城市製造設計，透過即時抓取市場原物料價格與黑市高額收購訂單，結合工坊製造返還率（RRR）、手續費模型、玩家專精等級與隨身日誌產出，自動計算全量無神器裝備的淨利潤、投報率（ROI）與每日暴利潛力。

## ⚙️ 核心特色與量化模型

1. **🏰 皇家城市製造分頁 (Royal City Manufacturing Arbitrage)**：
   - 獨立對比白城（礦石/布）、綠城（木材/皮）、黃城（布/鐵）、藍城（皮革/木）、紫城（礦石/木）各製造裝備的產地原料直購成本。
   - 套用專屬製造加成（無專注 24.8% / 下專注 47.9%），直接計算運往黑市出貨之淨利、ROI 與隨身日誌收益。
2. **🦣 猛獁之路任務系統 (Road to 360M Mammoth 💀)**：
   - 專為手頭資金 20M 設計的進階任務樹與每日作戰清單，直達 360M 提領 T8 運載猛獁象。
   - 4 階段戰略規劃（階段 I: 20M➔50M、階段 II: 50M➔120M、階段 III: 120M➔240M、階段 IV: 240M➔360M）+ 一鍵智慧選品過濾。
3. **💾 專精配置永久保存 (data/specs.json)**：
   - 玩家輸入的內圈母節點（0~100）、外圈專精（0~100）與料理食物設定自動防手震同步儲存至 `data/specs.json`，換裝置或重整網頁不遺失。
4. **官方多重擲骰品質機率與向下相容期望價 (Multi-Roll Expected Value)**：
   - 結合玩家真實專精計算品質骰機率，以黑市向下相容機制計算期望售價：
     $$\mathbb{E}[\text{Price}] = \sum_{k=1}^5 P(Q_k) \cdot \max_{1 \le i \le k} P_{Q_i}$$
5. **紅城島 15 位 T6 獵人工人專屬循環**：
   - T6 獵人裝備日誌全額送入島嶼，產出 144 個精煉材料（預估單日獲利 200k~300k 銀幣）。
   - 批量清單一鍵折抵工人產出，降低採購本金。
6. **每日暴利潛力榜首 (Daily Profit Potential)**：
   - `單件淨利潤 × 日均銷量`，直擊真正暴利爆款商品！

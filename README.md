# 阿爾比恩量化帝國 - 黑市套利雷達系統

本系統專為《阿爾比恩 Online (Albion Online)》皇家大陸紅城（Caerleon）黑市交易設計，透過即時抓取市場原物料價格與黑市高額收購訂單，結合工坊製造返還率（RRR）與手續費模型，自動計算全量無神器裝備的淨利潤與投資報酬率（ROI）。

## 🚀 快速啟動

1. **一鍵啟動**：
   - 雙擊執行目錄下的 `啟動黑市雷達.bat`。
   - 系統會自動啟動 FastAPI 服務並在預設瀏覽器開啟 `http://localhost:8000`。
2. **手動指令啟動**：
   ```bash
   python app.py
   ```
3. **搭配封包監聽（推薦）**：
   - 進入 `Albion Data Client/` 目錄並執行 `albiondata-client.exe`。
   - 在遊戲內開啟集市或黑市瀏覽，數據即會自動即時更新至 AODP。

## ⚙️ 核心演算法與批量製造功能

1. **材料總成本與實質生產成本**：
   - 依據紅城各階級原物料（木、皮、鐵、布）出售價與配方計算。
   - 考慮紅城無專精 15.2%（或專注 47.9%）資源返還率，並加入每日工坊活動加成。
2. **黑市訂單深度與 7 天均價**：
   - 深度查詢 AODP 歷史成交數據，統計 7 天銷量、日均消化速度與一週均價。
   - 提供流動性等級（高流通 ≥50/日、中流通 10~49/日、低流通 <10/日），確保大批量出貨能順利成交。
3. **批量掛單稅率 (6.5%) vs 即時砸單 (4.0%)**：
   - 即時砸單：尊爵特權 4% 稅率。
   - 批量掛單：4% 交易稅 + 2.5% 掛單設置費 = 6.5% 總成本。
4. **官方多重擲骰品質機率與向下相容期望價 (Multi-Roll Expected Value)**：
   - 官方多重擲骰機制：$N = 1.0 + (\text{Quality Bonus} / 100)$ 次擲骰，取最高品質。
   - Quality Bonus 來源：內圈母節點 (0~100)、外圈專精 (0~100)、料理食物（T6 馬鈴薯沙拉 +100 / 阿瓦隆深海怪沙拉 +200）與專注 (+50)。
   - 批量期望售價結合黑市向下相容保底有效價：
     $$\mathbb{E}[\text{Price}] = \sum_{k=1}^5 P(Q_k) \cdot \max_{1 \le i \le k} P_{Q_i}$$
5. **紅城島 15 位 T6 獵人工人專屬循環策略**：
   - 工人產出：獵人工人產出以皮革為主（50%）、木板（25%）、鐵錠（25%）。
   - 專屬 T6 通道：為最大化 15 位工人 22hr 產能，系統將 T6 獵人裝備日誌全額送入島嶼（做約 5 件弓即可填滿 15 本，產出 144 個精煉材料，預估單日獲利 200k~300k 銀幣）。
   - T4/T5 或非獵人日誌自動切換為市場掛單直售，不浪費工人 CD。
   - 批量清單一鍵抵扣工人產出，降低批量採購本金。
6. **每日暴利潛力榜首 (Daily Profit Potential)**：
   - `單件淨利潤 × 日均銷量`，直觀掌握每日預期套利上限，直擊真正暴利爆款商品！
7. **猛獁之路任務系統 (Road to Mammoth: 20M ➔ 360M)**：
   - 專為手頭資金 20M 設計的進階任務樹與每日作戰清單，直達 360M 提領 T8 運載猛獁象 💀。
   - 4 階段戰略規劃 + 一鍵智慧選品過濾，自動過濾無風險高周轉商品，解決資訊過載與手足無措！

## 📱 跨裝置使用指南 (手機 / 平板 / 另一台電腦)

### 方法一：同一區域網路連線 (最推薦！手機/平板免安裝直接用)
1. 確保目前這台電腦已執行 `啟動黑市雷達.bat`。
2. 查看終端機顯示的區網網址（例如：`http://192.168.31.208:8000`）。
3. 手機、iPad 或另一台筆電連上相同的 Wi-Fi，打開瀏覽器輸入該網址，即可直接瀏覽雷達行情、操作篩選與同步記帳！

### 方法二：複製至另一台 Windows 電腦獨立運行
1. 將專案資料夾複製到新電腦（可略過 `archive/` 與 `graphify-out/`）。
2. 在新電腦安裝 Python 3 (安裝時務必勾選 `Add python.exe to PATH`)。
3. 雙擊執行 `啟動黑市雷達.bat`，批次檔會自動檢測並一鍵安裝所需依賴套件 (`requirements.txt`)。
4. 若新電腦亦有玩遊戲，可執行 `Albion Data Client/albiondata-client.exe` 進行封包監聽。
